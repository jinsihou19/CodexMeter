# 本机统计与成本估算

CodexMeter 的“本机统计”是一个只读聚合功能，用于把 Codex 本地状态整理成菜单栏和 Widget 可以快速展示的摘要。它不读取 OpenAI 账单，也不会把会话正文写入 CodexMeter 的缓存。

## 数据链路

1. 从当前 `CODEX_HOME`（未设置时为 `~/.codex`）读取 `state_5.sqlite`，获取线程、Token、项目和最近任务的索引信息。
2. 从 `session_index.jsonl` 补充 Codex 侧边栏标题；从 `automations/*/automation.toml` 识别启用中的定时任务。
3. 按数据库引用的 rollout 文件解析可识别的 Token 事件，并按天、模型和项目聚合。
4. 将最近一次可用结果写入本机缓存，供主应用和 Widget 在下一次启动时快速显示；任务标题只在应用内存中展示。

读取使用系统 `sqlite3` 的只读模式。数据库缺失、权限不足、schema 变化或单个 rollout 无法解析时，网络额度仍可正常刷新；可用数据不足时，界面会显示“部分统计”。

## 展示内容

- 今日、近 7 天和累计 Token
- 近 190 天的每日 Token 趋势
- 今日进行中、待处理、定时和已完成任务数量
- Token 使用量最高的项目（最多 5 个，只保留目录末级名称）
- 本月输入、缓存输入、输出 Token 以及 API 等效成本

## 成本口径

已知模型按代码内置的 OpenAI 官方历史价格表计算：

```text
非缓存输入 × 输入单价 + 缓存输入 × 缓存输入单价 + 输出 × 输出单价
```

实现会按事件日期选择价格；已支持的长上下文价格也会按单次输入量处理。未知模型不猜价，无法完整解析的会话不计入已定价会话数。

因此，界面中的金额是“API 等效成本”，用于比较使用量，不代表订阅账户实际产生了同额账单。

## 隐私边界

- 本机统计读取本地 Codex 数据，不上传 rollout、prompt、transcript 或工具输出。
- 共享快照只保留数字摘要、项目末级名称和计数，不保存完整路径或任务标题。
- 诊断日志只记录读取阶段、错误原因和聚合数量，不记录会话正文。
- 需要排查读取问题时，可在“设置 → Codex”中打开日志目录；删除缓存不会影响 Codex 原始数据。
